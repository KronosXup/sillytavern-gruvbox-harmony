# Gruvbox Harmony v2.3

头像大卡系统完善与默认策略调整、世界书系列修复、柏宝书/构画插件适配、「外观速调」酒馆助手脚本首发。正式主题收敛为 20 套（Lite / Online 系列已于 v2.2 后归档停维）。

---

## 头像显示系统

- **电影大卡（mode0）**：顶部居中 16:9 大图 + 相框板 + 海报式信息行；桌面卡宽随列宽收敛（窄列 85% 留白不顶满，宽列 500px 封顶），名字行防越界裁切、长名自动省略号
- **传统小圆头像（mode1）**：移动端头像放大至 44px，名字缩进与计数器位置自动联动；计数器垂直内边距对齐桌面观感
- **默认切到 mode1**：服务端头像缩略图仅 96×144，大卡拉伸必糊，小圆头基本无损。想回大卡：用配套的外观速调脚本面板一键切换（推荐），或主题源码 `01-head.scss` 里 `--avatar-mode` 改回 `0` 重新构建

## 新增：外观速调脚本 v4.1.0（userscripts/ 目录）

不重编主题就能现场调观感的酒馆助手脚本，导入即用：

- **字体分类管**：正文 / 界面 / 等宽三类字体分开调，实时预览
- **头像一键切换**：面板里直接切电影大卡 / 传统小圆（默认小圆后想要大卡的用户用它即可，无需换主题包）
- **大面板居中**：毛玻璃面板屏幕正中，JS 像素硬定位（修掉移动端百分比定位被地址栏伸缩顶到屏幕顶的 bug）
- **一键重置**：调坏了随时恢复默认
- 安装方式：酒馆助手 → 脚本管理 → 导入 `userscripts/酒馆助手脚本-外观速调.json`

## 世界书系列修复

- **条目头错位**：修复深度/顺序/触发% 三个数字框比标题框上浮 3px+（主题全局 select 边距覆盖了 ST 原生清零类，已豁免）
- **跳转标题截断**：从角色卡跳转世界书时长标题锁死单行的 bug，改用浏览器原生 field-sizing 定高（需 Chrome/Edge 135+，旧内核维持原行为）
- **位置下拉定宽**：卡到「插入深度」标签长度，尾巴自动省略号，弹层选项仍完整显示
- **下拉折行**：桌面 base-select 弹层里「角色定义」等长选项不再折两行
- **窄屏溢出**：大量启用世界书时多选区按最长书名撑破屏幕、条目头图标被顶出界外，已修复
- **装饰线收窄**：标题下横线装饰不再误画进条目内部

## 插件适配

- **柏宝书（BaiBai-Book）**：移动端编辑按钮不再压摘要卡（编辑态留白 44→92px）
- **构画（SevenDaysCal）**：仪表盘盒与柏宝书卡之间的大空隙消除；移动端构画盒与柏宝书卡左右缘对齐（复刻 PC 观感）
- **关键词过滤插件**：界面图标补 Phosphor（主题切换/重命名/暗色/净化/十字准星/对比弹窗等）
- **扩展菜单**：图标与文字左缘对齐（统一槽宽 1.25em），魔法棒菜单图标光学补偿

## 其它

- **hover 光晕**：修复暗色 hover 光晕延迟突亮（过渡恢复即刻渐亮）
- **配色纯净度**：清除全系硬编码 Blue 污染，hover 光晕/斜纹纹理改用各主题自己的 accent
- **自定义字体防丢**：字体定义支持本地覆盖文件（`_fonts-local.scss`），拉新版不丢自定义字体
- **推理块**：展开限高 55vh + 内容滚动，收起点始终可见；手机端右侧贴齐

## 维护性变更（用户无感）

- 架构迁移至 SCSS 源层 + 构建脚本：日后样式调整只改一处，20 套自动同步；二创指南见 README

### 升级须知

- 升级后需**切换一次主题**（切到别的再切回来）让 ST 重新加载 custom_css，手机端同样
- 本次发布包为 20 套正式主题（Harmony 5 + Harmony Light 5 + Material 10）；Lite / Online 系列已归档停维，旧版可继续使用不再更新
- 未安装柏宝书 / 构画 / 关键词过滤的用户不受对应适配影响
- 外观速调脚本为可选组件，不导入不影响主题本体
