# Gruvbox Harmony v1.5 更新

缝缝补补

## 新增版本
- Lite 版：酒馆原生图标，给喜欢默认图标的多一个选择

## 移动端
- 聊天正文补回背景色 + 斜线纹理，显示效果与 PC 端更接近
- 输入栏贴底，不再露背景缝
- **注意事项：移动端建议在用户设置里勾选「减少动态效果」来降低卡顿感！这好像是酒馆问题我没招了**

## 全平台
- **悬停特效光晕配色修正**：之前所有配色都用了 Aqua 色，现在各自用自己主题色
- **头像形状跟随设置**：现在可以自由选择头像形状了（矩形因影响正文排版，聊天区正文头像仍是圆角正方形）
- 头像选中 / 收藏 / 默认人设外框统一主题色
- AI回复格式化图标更换
- select2 激活标签（世界书等）：X 与名字等高整块圆角，加分隔线，不盖字
- 骰子插件导航栏固定底部模式问题修复
- 输入框文本高度对齐图标

## 版本选择

| 版本 | 图标 | 大小 |
|------|------|------|
| Harmony | 内联 SVG，图标在本地 | ~270KB |
| Online | 图标外链，联网加载图标 | ~145KB |
| Lite | 图标为酒馆默认，最轻 | ~50KB |

5 配色：Aqua / Green / Orange / Pink / Purple
