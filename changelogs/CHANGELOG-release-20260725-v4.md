# Gruvbox Harmony v4

修修补补一通，这版算稳一点了。

## 移动端
- 聊天框补回背景色 + 斜线纹理
- 删除模式输入栏同款背景，与聊天框贴合
- 输入栏贴底，不露背景缝
- 计数器蒙版与名字/日期起点对齐
- 编辑展开按钮右移，不挡计数器

## 全平台
- hover 光晕各配色用自己主题色（以前全是 Aqua）
- 头像形状跟随 ST 设置（圆/方/圆角/矩形）
- AI 格式化图标 → 空心四角星
- fa-robot → CPU 芯片
- 选中/收藏/默认人设外框统一 Quote 色
- select2 / ACU / textarea 等小修
