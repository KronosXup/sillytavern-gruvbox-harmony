# Gruvbox Harmony v2.0

大版本更新：新增浅色 Light 家族、暗色系配色正名、下拉菜单主题化、40+ 细节修复、体积减重、正式开源。

---

## 新增：Light 浅色家族（5 套）

| 变体 | 主色 | 色源 |
|------|------|------|
| Blue-Light | `#076678` | 官方 faded_blue |
| Green-Light | `#79740e` | 官方 faded_green |
| Orange-Light | `#af3a03` | 官方 faded_orange |
| Purple-Light | `#8f3f71` | 官方 faded_purple |
| Violet-Light | `#9966cc` | 自调色（与暗色 Violet 同源） |

### 亮色版和暗色版的区别

- **底色**：暗色系是深炭底（`#1d2021`）；亮色系用 Gruvbox 官方 light 色板，奶油纸色底（`#f9f5d7`）
- **主色**：暗色系用 bright 系高亮色（深底上要亮）；亮色系用 faded 系深色（浅底上要压得住），两边同名不同值是有意为之
- **文字**：暗色米色正文，亮色深灰正文；代码高亮也各配了明暗两套
- **动效**：暗色系的 hover 光晕、发送键半透明呼吸等"发光系"效果在浅底上不成立，亮色版已移除，整体观感更安静；羽毛笔发送键常显实色
- **兼容适配**：亮色版对 ST 本体及常见扩展（酒馆助手、小白X 等）写死的暗色颜色做了全面重适配——标签、红底按钮图标、灰色辅助文字、勾选框等在浅底下均可读

## 暗色系正名（升级后需要重选主题！）

对齐 Gruvbox 官方色名，三个变体改名，**色值完全不变**：

| 旧名 | 新名 | 主色 | 原因 |
|------|------|------|------|
| Aqua | **Blue** | `#83a598` | 官方色名就是 blue |
| Pink | **Purple** | `#b16286` | 官方色名就是 purple |
| Purple | **Violet** | `#9966cc` | 自调色，让位官方名 |

Green / Orange 名实相符，不动。

⚠️ 主题按名字记忆，改名后酒馆里的旧选择会失效：升级后请在 UI 主题下拉里重新选一次。

## 下拉菜单主题化（桌面端）

桌面 Chrome / Edge 135+ 上，下拉菜单展开的弹层改为主题渲染：圆角、主题底色、✓ 标记当前值、悬停高亮跟随各配色主色。手机端与其他浏览器保持系统原生弹层，不受影响。

## 图标

- 补齐 12 个漏网图标（提示词管理器、群聊、图像生成、常见扩展等处）
- GitHub / Discord 图标换用 Phosphor 同族线条版，与相邻图标视觉等大
- 修正 ⇄ 图标误配与尺寸；红底按钮（删除类）图标在亮色版改浅色

## 细节修复（节选）

- 提示词管理器：启用条目的控制图标实色显示，与禁用条目明确区分
- 双滑块（STscript 宽度等）圆球不再被色条盖住
- 下拉框箭头跟随主题色（原为固定灰）
- 颜色选择器按钮圆角
- 输入建议框不再显示误导性的下拉三角
- 面板顶部提示条与帮助问号不再被滚动内容遮挡

## 体积

无损减重：Harmony 系单文件 278KB → 232KB（-17%），纯编码优化，渲染效果零变化。

## 升级方法

1. 酒馆里删除旧版主题（特别是旧名 Aqua / Pink / Purple 系列）
2. 从对应系列目录导入新 `.json`
3. UI 主题下拉重新选中
