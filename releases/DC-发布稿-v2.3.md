**Gruvbox Harmony v2.3 发布** 🎉

头像系统完善 + 世界书系列修复,另附一个新玩具:**外观速调脚本**。正式主题收敛为 **20 套**(Lite / Online 归档停维)。

**头像显示**
- 默认切换为传统小圆头像:酒馆头像缩略图仅 96×144,电影大卡拉伸必糊,小圆头基本无损
- 电影大卡模式保留,想要大卡可找作者要 mode0 版
- 移动端小圆头放大到 44px,桌面大卡窄列自适应不再顶满

**新玩具:外观速调脚本 v4.1.0**(userscripts/ 目录,可选)
- 酒馆助手脚本,导入即用,不重编主题现场调观感
- 头像大卡/小圆一键切换(想要电影大卡的用它切,不用换主题包)
- 正文/界面/等宽三类字体分开调,实时预览
- 毛玻璃大面板屏幕正中,手机不再卡顶
- 一键重置,调坏不慌

**世界书修复**
- 条目头深度/顺序/触发% 不再比标题框上浮错位
- 角色卡跳转世界书时长标题不再锁死单行(需 Chrome/Edge 135+)
- 位置下拉定宽,长标签自动省略号;桌面下拉长选项不再折行
- 大量启书时窄屏撑破屏幕的溢出修复

**其它**
- 暗色 hover 光晕延迟突亮修复
- 清除全系硬编码蓝色污染,各主题 hover 光用自己的 accent
- 推理块展开限高滚动,收起点始终可见

📦 升级后记得**切换一次主题**(切走再切回)让样式重载,手机同理。外观速调脚本在包里 userscripts/ 文件夹,酒馆助手导入 JSON 即可。
