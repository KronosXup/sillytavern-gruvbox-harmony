花了大半天搓出来的主题，结果越修越停不下来，现在是 v2.0：四个系列共 20 套。

Gruvbox 配色 + 鸿蒙字体 + Phosphor 图标 150+ 全套替换。手机端背景透明度可能偏高，因人而异。

使用 ```/下载``` 打包下载，或去 GitHub 拿最新版、完整更新日志和全部色值：
https://github.com/KronosXup/sillytavern-gruvbox-harmony （MIT，欢迎二改）

**系列**：Harmony 暗色主力 ｜ Lite 轻量（保留原生图标）｜ Light 浅色奶油底 ｜ Online 图标外链更小

**配色**：Blue · Green · Orange · Purple · Violet，明暗对称各五套——暗色用 bright 高亮色，Light 用 faded 深色，同名不同值。

⚠️ **v2.0 改名**：Aqua→Blue、Pink→Purple、旧 Purple→Violet（对齐官方色名，色值未变）。主题按名字记忆，升级后请重新选一次。

**特性**：全面圆角化（PC，一路圆到下拉弹层）· 羽毛笔发送 + 墨线动效 · 底部按钮动效 · 引号/标题左竖线 · 桌面下拉弹层主题渲染（Chrome/Edge 135+，✓ 标当前值）· Light 系含酒馆助手/小白X 等扩展的浅色适配，发光动效移除更安静
