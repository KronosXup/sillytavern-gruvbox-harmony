# Gruvbox-Harmony 酒馆主题 — DC 首楼（v2.0）

花了大半天搓出来的主题，结果越修越停不下来，现在是 v2.0 了：四个系列共 20 套。

Gruvbox 配色 + 鸿蒙字体 + Phosphor 图标 150+ 全套替换。

注意手机端可能背景透明度会高些，因人而异。

使用 ```/下载``` 打包下载，或去 GitHub 拿最新版和完整更新日志：
<https://github.com/KronosXup/sillytavern-gruvbox-harmony>（MIT，欢迎二改）

## 四个系列

| 系列 | 说明 |
|------|------|
| Harmony | 暗色主力，图标全套替换 |
| Lite | 轻量版（52KB），保留 FA 原生图标 |
| Light | 浅色版，官方 light 色板奶油纸底 |
| Online | 图标走外链，文件更小 |

## 配色（明暗对称五色）

暗色用 bright 高亮色、亮色用 faded 深色——同名不同值，浅底上才压得住：

| 配色 | 暗色系 | Light 系 |
|------|--------|----------|
| Blue | `#83a598` | `#076678` |
| Green | `#b8bb26` | `#79740e` |
| Orange | `#fe8019` | `#af3a03` |
| Purple | `#b16286` | `#8f3f71` |
| Violet（自调） | `#9966cc` | `#9966cc` |

⚠️ **v2.0 改名提醒**：Aqua→Blue、Pink→Purple、旧 Purple→Violet（对齐 Gruvbox 官方色名，色值全都没变）。主题按名字记忆，升级后请重新选一次。

## 功能特性

- **鸿蒙字体** — HarmonyOS Sans SC，代码块 JetBrains Mono
- **全局图标替换** — 150+ FA → Phosphor 线性图标
- **羽毛笔发送按钮** — 书写轨迹墨线动效
- **底部三按钮动效** — 汉堡抖动 / 星星闪烁 / 发送发光
- **引号特效** — 左竖线 + 微背景 + 圆角
- **标题统一** — 左竖线 + 圆角边框
- **全面圆角化（PC）** — 按钮、输入框、面板、滑条一路圆到下拉弹层（Chrome/Edge 135+ 弹层主题渲染，✓ 标当前值）；移动端保持原生不受影响
- **暗纹背景** — 极淡交叉线叠加层
- Light 系另做了全套浅色适配（含酒馆助手、小白X 等扩展的暗色硬编码修复），发光系动效移除，观感更安静
